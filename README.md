# 🚖 MOVU

## Slogan
Movendo pessoas. Conectando destinos.

## Objetivo
A MOVU é um aplicativo para ajudar motoristas particulares a gerenciar clientes, corridas e faturamento.

## Funcionalidades
- Cadastro de clientes
- Nova corrida
- Histórico
- Financeiro
- Recibo por WhatsApp
